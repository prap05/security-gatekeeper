# Security policy

## Supported version

This portfolio project is maintained on the latest `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Instead, use GitHub's private vulnerability reporting feature when the repository is published, or contact the repository owner privately with:

- a concise description and affected version/commit;
- safe reproduction steps and expected versus actual behavior;
- potential impact; and
- a remediation suggestion, if available.

Please do not test against systems you do not own or have explicit permission to assess. Acknowledgement and remediation status should be provided within 7 days.
